# lessons.md — 跨阶段经验沉淀库

> L4 沉淀资产。本文件当前为空库（仅模板与写入协议），由每次阶段收尾按 `/stage-done` 追加。
> 只写**可复用**结论；一次性缺陷细节、代码结构、路径清单、临时进度不写这里。

## 1. 写入模板

每条经验固定为如下块，按时间正序追加到 §3：

```
### L-xx ｜ YYYY-MM-DD ｜ 阶段 <阶段号>

- **触发**：<在什么场景/检视项/评审中发现的>
- **结论**：<一句可复用的判断或做法，能被下一阶段直接采用>
- **归属**：<本阶段已收敛 / 移交阶段 xxx>
- **上升为**：<无 / 规则 0x / 项目记忆 / decisions.md 的 D-xx>
- **来源**：<python-code-review 报告 / 用户确认 / 验收项 x / handoff 路径>
```

## 2. 写入协议

1. 每次阶段收尾由 `memory-steward` 追加，编号递增；不修改、不删除已有条目
   （结论被推翻时追加一条「取代 L-xx」并同步更新对应规则/记忆）。
2. **写**：反复出现的问题模式、被用户确认或否决的做法、裁决适用边界、验收证据的有效形式。
3. **不写**：某次编译错误、某个函数实现细节、git 提交、临时状态、进度百分比。
4. 若结论需要约束所有人后续行为 → 上升为 always 规则或 `decisions.md` 的裁决，
   并同步项目记忆；仅本阶段适用就留在本文件。
5. 项目记忆写入前先查 `MEMORY.md` 去重；相对日期一律换算成绝对日期。
6. 检视报告中的跨阶段遗留项，在 `归属` 字段标明收敛阶段，不阻断当前阶段开工。

## 3. 已有条目

### L-01 ｜ 2026-11-10 ｜ 阶段 0

- **触发**：契约测试收集期因 Fake 侧类型断裂报 ImportError，连带阻断本阶段补测举证。
- **结论**：契约测试收集期 ImportError 会连带阻断其他阶段补测举证，允许经用户授权做 Fake 侧一次性最小修复（只对齐既有接口签名、不静默改接口），并在 `test-report.md` ⑥ 记录原属阶段与提前处置原因；同类阻塞先判归属阶段再处置、保留原验收项独立验收，不洗绿、不改被测实现、不改预期。
- **归属**：本阶段已收敛；`a-2` 独立验收移交阶段 a。
- **上升为**：项目记忆 / 无新规则。
- **来源**：用户裁决 + `stages/0/test-report.md` ⑥。

### L-02 ｜ 2026-11-10 ｜ 阶段 a

- **触发**：工具链失败（mypy `untyped-decorator`）落在 L1 契约层文件，且验收项要求工具链全绿。
- **结论**：当修复必须落在 L1 契约层时，先输出完整 diff（变更前后 + 影响面 + 受影响测试/Fake）并停下等用户明确批准，批准后才落地、落地后立即实跑三项工具链；收尾把「首次经用户批准的 L1 变更」登记进 `references/decisions.md` 与 handoff 作为后续 baseline 对比依据，后续 `contract-guard` 按「有变更 + 已批准」判定，不重复判 blocked / 不重复征询。
- **归属**：本阶段已收敛；后续阶段按 baseline 对比。
- **上升为**：项目记忆 + `decisions.md` 附录 A（**不新增 D-xx 裁决**）。
- **来源**：用户 2026-11-10 裁决 + `HANDOFF-a.md` §4 / §7 + `stages/a/test-report.md` ④。

### L-03 ｜ 2026-11-10 ｜ 阶段 a

- **触发**：资料口径与逐字段严格枚举不一致（Fake 字段标注缺口「9 处 / 10 处」），且用户已明确「不重写已有测试」。
- **结论**：口径差异由用户一次裁决收口后即写入 `spec-digest.md` §5、不再反复列为待确认项；既有测试不重写，未纳入单测断言的那一处由实现改动 + 三项工具链实跑 + 改动清单举证，并在 `test-report.md` ③ 附注说明、不列作该验收项的未覆盖项。
- **归属**：本阶段已收敛。
- **上升为**：无（仅本阶段适用）。
- **来源**：用户 2026-11-10 裁决 + `stages/a/spec-digest.md` §2.6 / §5 + `stages/a/test-report.md` ③ 附注 2。
