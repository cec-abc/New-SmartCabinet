# lessons.md — 跨阶段经验沉淀库

> L4 沉淀资产。本文件当前为空库（仅模板与写入协议），由每次阶段收尾按 `/stage-done` 追加。
> 只写**可复用**结论；一次性缺陷细节、代码结构、路径清单、临时进度不写这里。

## 1. 写入模板

每条经验固定为如下块，按时间正序追加到 §3：

```
### L-xx ｜ YYYY-MM-DD ｜ 阶段 <阶段号>

- **触发**：<在什么场景/检视项/评审中发现的>
- **结论**：<一句可复用的判断或做法，能被下一阶段直接采用>
- **归属**：<本阶段已收敛 / 移交阶段 xxx>
- **上升为**：<无 / 规则 0x / 项目记忆 / decisions.md 的 D-xx>
- **来源**：<python-code-review 报告 / 用户确认 / 验收项 x / handoff 路径>
```

## 2. 写入协议

1. 每次阶段收尾由 `memory-steward` 追加，编号递增；不修改、不删除已有条目
   （结论被推翻时追加一条「取代 L-xx」并同步更新对应规则/记忆）。
2. **写**：反复出现的问题模式、被用户确认或否决的做法、裁决适用边界、验收证据的有效形式。
3. **不写**：某次编译错误、某个函数实现细节、git 提交、临时状态、进度百分比。
4. 若结论需要约束所有人后续行为 → 上升为 always 规则或 `decisions.md` 的裁决，
   并同步项目记忆；仅本阶段适用就留在本文件。
5. 项目记忆写入前先查 `MEMORY.md` 去重；相对日期一律换算成绝对日期。
6. 检视报告中的跨阶段遗留项，在 `归属` 字段标明收敛阶段，不阻断当前阶段开工。

### L-05 ｜ 2026-11-11 ｜ 阶段 c1

- **触发**：`python-code-review` 检视新增 `IniConfigManager.loadConfig()` 时发现，只读捕获 `OSError` / `configparser.Error` 会放非法 UTF-8 的 `UnicodeDecodeError` 穿越模块边界。

### L-06 ｜ 2026-11-11 ｜ 阶段 c2

- **触发**：验收「唯一 BlockingQueue 异步消费」「停机清空队列并关句柄」时，仅靠「最终文件内容正确」无法证明业务线程未做磁盘 IO、停机未丢队列。
- **结论**：异步消费/落盘类模块的验收必须给「入队时文件内容为空 → 后台消费后落盘 → 停机后队列空且句柄全关」三段可观测证据；时钟、磁盘剩余比例、大小阈值等外部依赖一律注入回调而非读真实环境，使跨天/超限/磁盘清理可在 `tmp_path` 内确定性举证。停机路径要同时覆盖「未启动消费者」与「已启动并阻塞在 take」两种，并验证重复 stop 幂等。
- **归属**：本阶段已收敛；同类线程停机（采集/识别/TCP）在 `c3`~`c5`/`d` 沿用。
- **上升为**：检视经验库（新增「后台消费者停机三要素与可观测举证」检查项）；无新规则 / 无新裁决。
- **来源**：`stages/c2/test-report.md` ①③④⑥ + `HANDOFF-c2.md` §3 检视报告。

### L-07 ｜ 2026-11-11 ｜ 阶段 c3

- **触发**：`python-code-review` 检视 `TcpControlLayer.onLinkDown` 修复时发现，`BaseThread.start()` 带 `_hasStarted` 幂等保护，对一个已 `start()` 并退出的线程实例再次 `start()` 是静默 no-op，导致断线后重连线程无法重启、`linkState` 永远回不到 UP。
- **结论**：凡「断开后要重建/重启」的后台线程（重连、采集、识别等），**每次拉起都新建线程实例**而非复用旧实例；停线程时若调用线程恰为被停线程自身（如 decode 在 recv 空时调 `onLinkDown` 停自己），`BaseThread.stop()` 的 `self-join` 会抛 `RuntimeError`，`stopEvent` 已置位、线程会在 `runLoop` 退出条件满足后自行结束，故用 `try/except RuntimeError` 吞掉即可，不要因此不调 `stop()`。
- **归属**：本阶段已收敛；同类「断开→重建线程」范式在 `c4`/`c5`/`d` 沿用。
- **上升为**：检视经验库（新增「重连类线程每次拉起须新建实例」检查项）；无新规则 / 无新裁决。
- **来源**：`HANDOFF-c3.md` §3 `python-code-review` 报告 P2 项 + `stages/c3/test-report.md` ③ `test_c3_x_relink_after_down`。
