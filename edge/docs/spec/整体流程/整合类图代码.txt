' ======================== 核心连线关系 ========================

' 1. Main 调度
Main --> EdgeControl : 1. 调度
EdgeControl -right-> Main : 2. 停机

' 2. EdgeControl 实现三大回调接口 (竖向正交)
EdgeControl ..|> SignalSink
EdgeControl ..|> ICaptureSink
EdgeControl ..|> IRecognitionSink

' 3. EdgeControl 直调三大门面
EdgeControl --> TcpControlLayer : 下发指令
EdgeControl --> UsbController : 下发指令
EdgeControl --> RecognitionController : 下发指令

' 4. 门面依赖注入回调接口 (横向正交)
TcpControlLayer --> SignalSink : 注入
UsbController --> ICaptureSink : 注入
RecognitionController --> IRecognitionSink : 注入

' 5. 模块内组合持有
TcpControlLayer *-- TcpReconnectThread
TcpControlLayer *-- DecodeThread
TcpControlLayer *-- HeartThread
TcpControlLayer *-- Socket
DecodeThread ..> Socket : 调用recv
HeartThread ..> TcpControlLayer : 上报失败

UsbController *-- CaptureWorker
CaptureWorker *-- CameraDevice

RecognitionController *-- YoloEngine
RecognitionController *-- RecognitionWorker
RecognitionWorker ..> YoloEngine : 共享调用
RecognitionWorker ..> RecognitionUtils : 依赖

' 6. 基础服务实现与依赖
IniConfigManager ..|> IConfig
LogManager ..|> ILogger
LogManager *-- LogExecutor
EdgeControl --> IConfig
EdgeControl --> ILogger


' ======================== 排版控制线（隐藏线，用于强制各层位置） ========================
SignalSink -[hidden]down- TcpControlLayer
ICaptureSink -[hidden]down- UsbController
IRecognitionSink -[hidden]down- RecognitionController

TcpControlLayer -[hidden]right- UsbController
UsbController -[hidden]right- RecognitionController

TcpReconnectThread -[hidden]down- IniConfigManager
CaptureWorker -[hidden]down- LogManager
